# 🔥 NoteForge

A beautiful, dark-themed code editor built with Electron + React + CodeMirror.

---

## ⚡ Quick Start

### Option 1: Double-click to launch
Just double-click **`start-noteforge.command`** in Finder. It will install dependencies automatically on first run.

### Option 2: From Terminal
```bash
cd /Users/rishirrsr/Documents/ClaudeCode/Notepad++
npm install   # first time only
npm run dev
```

---

## ✨ Features

| Feature | Shortcut |
|---|---|
| New Tab | `⌘ T` |
| Open File | `⌘ O` |
| Save As | `⌘ ⇧ S` |
| Close Tab | `⌘ W` |
| Find | `⌘ F` |
| Find & Replace | `⌘ H` |
| Format Code | `⌘ ⇧ F` |
| Bold Text | `⌘ B` |
| Indent | `Tab` |
| Outdent | `⇧ Tab` |
| Undo / Redo | `⌘ Z` / `⌘ ⇧ Z` |
| Zoom In / Out | `⌘ +` / `⌘ -` |
| Reset Zoom | `⌘ 0` |

## 🎨 Supported Languages

JavaScript/JSX/TSX • Python • HTML • CSS • JSON • Markdown • Java • C/C++

## 🛠 Tech Stack

- **Electron** — native macOS app
- **React** — UI framework
- **CodeMirror 6** — editor engine
- **Vite** — bundler
